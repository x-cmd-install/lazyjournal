# lazyjournal

[English version](./README.md)

TUI for viewing logs from journald, auditd, file system, Docker and Podman containers, Compose stacks and Kubernetes pods with support for log highlighting and several filtering modes.

[![x-cmd/install — lazyjournal Code Quality Monitoring Repo Card](https://x-cmd.com/repo-card/lazyjournal.svg?lang=zh)](https://x-cmd.com/install/lazyjournal)

## 安装

```sh
x install lazyjournal
```
